# Personal Finance Manager

Desktop-приложение для учёта личных финансов на Python и Tkinter.

## Функциональность

- Учёт доходов и расходов.
- Категоризация операций (зарплата, инвестиции, продукты, транспорт, развлечения).
- Расчёт текущего баланса, общей суммы доходов и расходов.
- Аналитика по категориям в отдельном окне.
- Удаление выбранной операции.
- Автосохранение данных в CSV-файл и загрузка при запуске.
- Проверка введённых данных (сумма, дата, категория).

## Требования

- Python 3.7+.
- Tkinter (входит в стандартную поставку Python для Windows и macOS;
  в Linux может потребоваться установить пакет `python3-tk`).

Внешние зависимости не нужны — см. `requirements.txt`.

## Запуск

```bash
python finance_gui.py
```

1. Введите сумму операции.
2. Выберите категорию из выпадающего списка.
3. Укажите дату в формате `ГГГГ-ММ-ДД` (по умолчанию — сегодняшняя).
4. При необходимости добавьте описание.
5. Нажмите **«Добавить операцию»**.

Выбранную в таблице операцию можно удалить кнопкой **«Удалить выбранную»**
или клавишей `Delete`. Кнопка **«Показать аналитику»** открывает окно
с итогами и суммами по категориям.


## Формат данных

Операции хранятся в `transactions.csv` со столбцами:

| Столбец | Назначение |
| --- | --- |
| `Amount` | сумма операции |
| `Category` | название категории |
| `Type` | тип операции («Доход» или «Расход») |
| `Date` | дата в формате ГГГГ-ММ-ДД |
| `Description` | описание операции |

При запуске данные автоматически загружаются из файла, а после каждого
добавления или удаления — сохраняются обратно.
